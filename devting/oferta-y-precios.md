# DEVTING - Oferta inicial

## Recomendacion importante

Aunque quieras vender "a todos", para conseguir el primer cliente mas rapido conviene empezar con negocios que tienen urgencia comercial: restaurantes, servicios profesionales, tiendas, inmobiliarias, esteticas, talleres, constructoras, academias y emprendimientos con Instagram activo.

## Servicio 1: Presencia Digital Express

Para negocios que necesitan verse profesionales rapido.

Incluye:

- Landing page de 1 seccion principal + secciones de servicios, beneficios, contacto y WhatsApp
- Optimizacion basica de Instagram o LinkedIn
- Copy comercial
- Boton directo a WhatsApp
- Entrega en 5 a 7 dias

Precio inicial sugerido:

**CLP 180.000 a CLP 350.000**

## Servicio 2: Sistema de Captacion

Para negocios que quieren recibir prospectos de forma constante.

Incluye:

- Landing page optimizada para conversion
- Formulario o WhatsApp con mensaje prearmado
- Pixel o medicion basica
- Campaña inicial de Meta Ads o Google Ads
- 8 piezas de contenido
- Reporte mensual simple

Precio inicial sugerido:

**CLP 450.000 a CLP 850.000 + inversion publicitaria**

## Servicio 3: Automatizacion y Web

Para negocios que pierden tiempo respondiendo, cotizando o gestionando clientes manualmente.

Incluye:

- Sitio o mini sistema web
- Formulario inteligente
- Automatizacion de respuestas
- Base de datos simple de prospectos
- Integracion con correo, WhatsApp o planilla

Precio inicial sugerido:

**CLP 700.000 a CLP 1.500.000**

## Oferta para primer cliente

Para cerrar rapido, usa una oferta de entrada:

**"Te creo una landing profesional con WhatsApp, textos comerciales y optimizacion basica de tu perfil por CLP 180.000. Si no te gusta el primer borrador, no seguimos y no pagas el resto."**

Forma de cobro recomendada:

- 50% al iniciar
- 50% al entregar
